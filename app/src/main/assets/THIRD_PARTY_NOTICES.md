They are delivered as GitHub Release assets, installed into app-private `noBackupFilesDir/lib`, and verified against manifest size and SHA-256 before use. The app build recipe is available at https://github.com/treeklyz-afk/Idownld/blob/main/scripts/build-aria2-android.sh . OpenSSL 3.5.9 is statically linked for HTTPS. yt-dlp uses aria2 for supported HTTP(S) transfers and keeps segmented HLS/DASH on its native downloader.

## Feature limitations in this build
The yt-dlp-ejs scripts remain embedded and QuickJS is fetched as a versioned helper runtime. Site extraction availability still depends on platform access rules, authentication, regional availability and current site behavior. FFmpeg JNI was removed because it was not connected to yt-dlp's merge path; separate-stream merging and format conversion are not promised, so muxed formats or audio-only streams may be needed.
